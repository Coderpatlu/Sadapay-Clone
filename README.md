# Sadapay-Clone
Sadapay-Clone is a React and Express digital wallet with MongoDB-backed accounts and simulated transfers. A user registers or logs in, completes MPIN and wallet onboarding, then can inspect balances and history or send money: recipient lookup precedes review, MPIN confirmation, transfer processing, and receipt display. The graph includes profile, wallet, authentication, and transaction capabilities documented in the README. Several frontend-to-backend links are dashed because the excerpts show the API paths and server routes separately, not their runtime HTTP exchange.
